# HR Employee Attrition Analysis

## Overview
This project analyzes employee attrition data using Power BI and Excel to identify key factors influencing employee turnover and workforce retention.

## Tools Used
- Power BI
- Microsoft Excel

## Dataset Information
The dataset contains employee demographic, job-related, and performance-related information used for attrition analysis.

## Objectives
- Analyze employee attrition trends
- Department-wise attrition analysis
- Job role analysis
- Salary and overtime impact analysis
- Workforce demographic insights

## Project Files
- HR_Employee_Attrition_Analysis.pbix.zip
- hr_attrition_cleaned.csv.xlsx
